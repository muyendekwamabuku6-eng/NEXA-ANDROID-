# NEXA Android V1 — Complete Source

This is the native Android source for the first NEXA mobile application.

Included:
- Home/social foundation
- Jobs
- Create-post screen
- Messages foundation
- Profile
- Android navigation
- Internet permission for backend connection
- Android project configuration

Important:
This package is SOURCE CODE, not a compiled APK. The APK must be compiled with an Android SDK/Gradle build environment.

Recommended build:
1. Open the folder in Android Studio.
2. Allow Gradle to sync.
3. Build > Build APK(s).
4. Install the generated debug APK on the Samsung A05.
